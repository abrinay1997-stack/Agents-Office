# Léxico: palabras permitidas y prohibidas

Jerga prohibida: Jamstack, CDN, LCP, SSG, headless, stack, deploy, framework, Lighthouse, Core Web Vitals, pipeline, onboarding, scope creep, Astro, Supabase, API, backend, frontend.
Relleno prohibido: soluciones, transformación digital, presencia en línea, sinergia, potenciar, impulsar, llevar tu negocio al siguiente nivel, apasionados, innovador, de vanguardia, experiencia de usuario excepcional, atención personalizada, precios competitivos.
Lujo prohibido: premium, exclusivo, boutique, VIP, élite, alta gama, selecto, líder, referente del mercado, los mejores de Panamá.

Permitidos (el cliente ya los reconoce): WordPress, Google, WhatsApp, Instagram, Facebook, Messenger, Telegram, Yappy, PayPal, GitHub, Cloudflare, dominio, alojamiento, complemento.

Vocabulario propio:
- Módulos → capacidades avanzadas
- Landing page → una página, larga y a medida
- Plugin → complemento
- Hosting → alojamiento, o «publicación incluida»
- CMS / panel admin → un panel para que edites el contenido tú mismo
- Backups → copia de seguridad automática
- Uptime → vigilado día y noche por si se cae
- WAF → un filtro delante que bloquea los ataques
- 2FA → verificación en dos pasos
- Leads → quién preguntó, qué quería y por dónde entró
- Revisiones → rondas de cambios

Formato: precios con coma de miles ($1,200); rangos con guion corto sin espacios ($80–$150, 4–5 días); guion largo — para incisos; comillas «» en prosa. Sin emojis, sin exclamaciones, sin mayúsculas de énfasis.
