# Proveedores y plataformas de PanaClaw

Lo que está documentado en los repositorios de PanaClaw. Los importes que se paga a cada uno NO están registrados aquí: si hacen falta, se piden al dueño, no se estiman.

| Plataforma | Para qué la usa PanaClaw |
|---|---|
| Netlify | Aloja el sitio panaclaw.com, recibe los envíos del formulario (Netlify Forms) y corre la función del chat |
| Cloudflare | El hub interno (cotizador y libreta de clientes, detrás de Access) y el CRM/eBot; los eBot de clientes viven en la cuenta Cloudflare de cada cliente |
| GitHub | Los repositorios: PanaClaw, PanaClaw-WorkSpace, CRM-PANACLAW, Agents-Office |
| Meta | Píxel del sitio, Instagram (pana.claw), Facebook (panaclaw), anuncios y WhatsApp Business |
| Google | Search Console; Analytics 4 y Business Profile pendientes; cuenta panaclaw507@gmail.com |
| Anthropic / Groq | Claves de IA del chat del sitio (en Netlify, nunca en el repo) |
| Registrador del dominio panaclaw.com | Confirmar con el dueño cuál es; el dominio se renueva cada año |

Avisos que importan: renovación del dominio · cambio de política o de precios de Meta (la ventana gratuita de 24 h de WhatsApp termina el 2026-10-01) · un modelo de IA retirado (ya apagó el chat una vez) · cargos inesperados · avisos de seguridad o de acceso.
Nunca se comparten claves ni tokens por correo, y nunca se pegan en un documento.
