# Skills

A skill is how you want one kind of work done. The ones here are examples for the sample
studio: some bound to an agent, some to a department (`plan-contenido` teaches the Marketing agents to leave content drafts in Contenido), one to everyone. Yours go in
`<brain>/Agents Office/skills/` so they live with your notes. The guide is [SKILLS.md](../SKILLS.md).
